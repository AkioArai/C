Как читать картину

  • Компьютер — сверху. Экран: всё, что вывела программа; ↵ — перевод строки \n. Буфер клавиатуры: введённые символы ждут, пока их заберёт scanf.
  • Кадр функции — рамка с кодом функции; подсвечена выполняемая строка. Справа от if — да/нет, у цикла — ×N.
  • Карточка переменной — имя, тип и размер справа, значение крупно. Цвет — тип: int, double, char.
  • Красная штриховка — «мусор»: значение ещё не задано.
  • Таблица цикла — значения переменных после каждой итерации.
  • Стрелки и лучи — указатели и движение данных; по лучу летит само значение.
  • Панель «Операция» — разбор шага картинками: формат printf, буфер scanf, деление, сравнение, логика, индексы…

Наведите мышь на любой элемент — появится подсказка. Нажмите на карточку — её паспорт с историей значений.

Нажмите «Запуск» — и программа оживёт

Здесь появится память вашей программы: экран, клавиатура, функции и переменные. Каждый шаг виден, каждую строку можно разобрать.

Как писать код быстрее

1. Шаблоны: слово → готовый код

Наберите слово в начале строки и нажмите Enter или →. Tab переводит к следующему полю шаблона.

progвся заготовка: #include, main, return 0
pf · sfprintf("%d\n", x); и scanf("%d", &x);
pfd · sfdто же для вещественных: %.2f и %lf
fori · forrцикл от 0 до n−1 и обратный
if · ife · elifветвления со скобками
arrin · arroutввод и вывод массива
sum · max · swapсумма, наибольший элемент, обмен
eps · bis · kahanсравнение через ε, деление пополам, шаг Кохена
ptrобход массива указателем

2. Подсказки при наборе

Достаточно первых букв, даже не подряд: prf → printf, sq → sqrt.

→ / Enterпринять подсказку
CtrlSpaceпоказать подсказки сейчас
после %список спецификаторов: в scanf первым идёт нужный
после #include <список библиотек
внутри ( )какие аргументы ждёт функция

Скобки и кавычки закрываются сами. Отступ после { ставится сам.

3. Компилятор исправляет сам

Ошибка видна сразу, прямо в строке кода. Под редактором — что не так и кнопка с готовой правкой.

AltEnterисправить ошибку в строке: ;, &, ==, %lf, #include…
ShiftAltEnterисправить всё, что можно
F4перейти к следующей ошибке
CtrlZотменить любую правку
Автозапускгалочка под редактором: вывод программы виден, пока вы пишете

4. Запуск и проверка

F5запуск с анимацией, пауза, продолжить
F8сразу результат, без анимации
F10 · ShiftF10шаг вперёд и шаг назад
ShiftF5остановить
номер строкинажмите — точка останова

Чтобы не вводить данные каждый раз, впишите их в «Входные данные заранее» или нажмите «Запомнить этот ввод» после запуска.

5. Правка без мыши

CtrlDдублировать строку
Alt↑ / Alt↓переместить строку
Ctrl/закомментировать строки
Tab / ShiftTabсдвинуть выделенные строки
ShiftAltFвыровнять весь код
CtrlF · CtrlHнайти и заменить
Ctrl= / Ctrl−размер шрифта кода

6. Логи вместо отладочных printf

Не нужно вставлять printf, чтобы узнать значение переменной.

Объяснениявкладка внизу: что сделала каждая строка
имя переменнойнажмите — вся история её значений
Таблицатрассировка: значения на каждом шаге
«к шагу»вернуть программу в любой момент
CtrlKпоиск по урокам, задачам, примерам и файлам
Поверните телефон горизонтально — так поместятся и код, и память программы.
