# Вселенная Си

**Визуальная лаборатория языка C.** Программа здесь — не текст, а пространство. Сначала оно пустое, как чистая память компьютера. Каждая строка кода что-то в нём меняет:

| В коде | На картине |
|---|---|
| `#include <stdio.h>` | на панели «Компьютер» появляется чип подключённой библиотеки |
| `int main(void) {…}` | открывается **кадр стека**: листинг функции с текущей строкой и карточки переменных |
| `int a;` | карточка `a`: тип, значение (или красное «? мусор»), размер в байтах клеточками |
| `int m[3][3]`, `char s[16]` | **мини-таблица** ячеек с индексами; строка показывается посимвольно, с `\0` |
| `struct`, указатели | карточка с полями; стрелка от указателя к объекту, подпись `→ g[0]`, `→ блок2` |
| `malloc` / `free` | блок в панели **Куча**; утечки подсвечиваются в конце |
| `printf("%d\n", a)` | полоска формата: `%d` — «целое число», `\n` — «перевод строки» ↵, откуда какое значение |
| `scanf("%d", &a)` | буфер клавиатуры посимвольно: какие символы забрал каждый спецификатор, что осталось |
| `if`, `switch` | вердикт условия и таблица «как вычислено»; для `switch` — какая метка совпала |
| `for`, `while`, `do` | скобка цикла со счётчиком ×N и **таблица трассировки**: значения после каждой итерации; у вложенного цикла — номер прохода |
| переполнение | **полоса диапазона** типа MIN…MAX: точный результат за краем и куда он «перескочил» |
| неинициализированная память | ячейка с красной штриховкой «мусор» |

## Возможности

- **Встроенный компилятор-интерпретатор C** на чистом JavaScript: работает прямо в браузере, без сервера.
  - Типы `char/short/int/long/long long` (signed/unsigned), `float/double`, `_Bool`, указатели (в том числе на функции), многомерные массивы и VLA, строки, `struct`/`union`/`enum`, `typedef`, `static`/`extern`, составные литералы и назначенные инициализаторы, `goto`, функции и рекурсия.
  - Модель памяти как у x86-64: стек, данные, строковые константы, куча; ловит выход за границы, разыменование NULL, повторный `free`, обращение к освобождённой памяти, утечки.
  - Препроцессор: макросы с параметрами, `#`, `##`, `#if/#ifdef/#elif`, `#undef`.
  - Переполнения, целочисленное деление, приведения типов работают как у gcc на x86-64.
  - `printf`/`scanf` с полным разбором форматов, включая точное округление, как в glibc.
  - Библиотеки: `stdio.h`, `math.h`, `stdlib.h` (в том числе `rand` с тем же генератором, что в glibc), `locale.h` (русская локаль и запятая в числах), `limits.h`, `float.h`, `stdbool.h`, `string.h`, `ctype.h`, `time.h`, `stdint.h`, `stddef.h`, `assert.h`; файлы (`fopen`, `fprintf`, `fscanf`, `fgets` …) в виртуальной файловой системе.
- **Диагностика на русском** в стиле gcc: `main.c:5:12: ошибка: …`, код строки со стрелкой `^~~` и 💡 подсказка, что делать. Ловит типичные ошибки новичков:
  - забытые `;` и `}`;
  - `scanf` без `&`;
  - `%f` вместо `%lf`, несовпадение формата и типа;
  - `=` вместо `==` и `;` после `if`/`for`;
  - неинициализированные переменные и целочисленное деление;
  - бесконечные циклы, `a < b < c`, отсутствующий `#include`;
  - «умные» кавычки из Word и русская раскладка.
- **Пошаговое выполнение**: запуск с анимацией, шаг вперёд и **шаг назад**, мгновенное выполнение, скорость, точки останова (нажмите на номер строки).
- **Подсказки при наборе**: напечатайте `sca` — появится `scanf(`, Tab дополняет; знает ключевые слова, функции подключённых библиотек и ваши переменные.
- **Мини-обучение** интерфейсу: экран затемняется, подсвечивается один элемент за раз (кнопка «Обучение» справа сверху).
- **Компьютер-терминал** с вкладками:
  - **Терминал** — компиляция, вывод программы, интерактивный ввод;
  - **Логи** — хроника каждого шага: что, где (строка и координаты), когда и почему; с фильтрами;
  - **Процессы** — всё, что сейчас существует во вселенной; нажатие переносит камеру к объекту;
  - **Проблемы** — ошибки и предупреждения с объяснениями.
- **Паспорт объекта**: нажмите на переменную, цикл, закон или область и увидите тип, адрес, координаты и историю значений.
- **Теория** по методическим указаниям (темы 1–4): 31 урок с запускаемыми примерами и мини-тестами «Проверь себя», шпаргалки по форматам и ошибкам.
- **Практика**: 46 задач (🟢 лёгкие, 🟠 сложные, 🔴 экстрим) с математическим уклоном. Автопроверка на тестах, подсказки, эталонные решения, прогресс.
- Интерфейс рассчитан на **ноутбук и планшет** (горизонтальный и вертикальный), управление мышью и касаниями (перетаскивание, масштаб двумя пальцами).

## Запуск

Сборка не нужна: это статический сайт на ES-модулях. Нужен любой локальный веб-сервер, потому что модули не грузятся по `file://`:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для публикации на **GitHub Pages**: Settings → Pages → Deploy from a branch → выбрать ветку и корень `/`.

## Тесты

```bash
npm test
```

- `tests/run.mjs` компилирует программы из `tests/programs/` настоящим `gcc` и сравнивает вывод с интерпретатором **байт в байт**.
- `tests/tasks.mjs` проверяет, что все эталонные решения задач дают в интерпретаторе тот же вывод, что и gcc, и что все примеры из теории компилируются.

## Структура

```
index.html              оболочка приложения
css/style.css           оформление (космическая тёмная тема)
js/app.js               маршрутизация: Вселенная / Теория / Практика
js/lab.js               лаборатория: связывает редактор, компилятор, вселенную и консоль
js/compiler/            компилятор-интерпретатор C
  lexer.js              лексер + препроцессор (#include, #define)
  parser.js             синтаксический анализатор → AST
  analyzer.js           семантические проверки и подсказки
  interpreter.js        пошаговое выполнение (генератор событий)
  format.js             printf / scanf (точное округление как в glibc)
  types.js, stdlib.js   модель типов, каталог библиотек
js/universe/            визуализация
  scene.js              состояние вселенной и реакции на события
  renderer.js           отрисовка на canvas, камера, жесты
  explain.js            объяснения шагов на русском
js/compiler/memory.js   побайтовая модель памяти (стек, данные, куча)
js/ui/                  редактор кода, подсветка, панель-компьютер
  stepview.js           панель «Операция»: формат printf, буфер scanf, таблица вычислений
js/pages/               страницы «Теория» и «Практика»
js/content/             уроки, задачи, примеры программ
tests/                  сверка с gcc
```
